# Nexus Task 3: Implemeting Quote of the Day Telegram Bot

## Features
- fetchs quotes from external API
- when user triggers `/quote` command, it sends random quote

## NPM Dependencies
- Axios
- dotenv
- Telegraf

## Installation
- clone the repository and 
- run `npm install` 
- run `node index.js`
